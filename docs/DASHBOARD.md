# Дашборд руководителя

Содержание объединено с основными руководствами, чтобы не поддерживать несколько версий одинаковых правил:

- [USER_GUIDE.md](USER_GUIDE.md) — как читать KPI, графики и список внимания.
- [BUSINESS_RULES.md](BUSINESS_RULES.md) — точные формулы, распределения, NULL и сортировка.
- [TECHNICAL_GUIDE.md](TECHNICAL_GUIDE.md) — реализация HTML/CSS, API refresh и stale data.
- [API.md](API.md) — контракт summary и пример нового seed.
- [TESTING.md](TESTING.md) и [TEST_RESULTS.md](TEST_RESULTS.md) — способы проверки и результаты; текущий набор 39 тестов.

Страница сохранена для совместимости прежних ссылок. Дополнительной аналитической БД и библиотеки графиков в проекте нет.
