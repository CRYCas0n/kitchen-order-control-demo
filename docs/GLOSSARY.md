# Словарь

| Термин | Значение в этом проекте |
|---|---|
| Заказ | Учётная запись изготовления/доставки/монтажа кухни с номером, стадией, сроками и суммами |
| Стадия | Текущее положение заказа в цепочке из десяти этапов; не статус отдельного задания |
| Первоначальный срок | Исходная дата обещания клиенту; запрос переноса её не заменяет |
| Прогноз | Записанная ожидаемая дата результата; не автоматически вычисленная производственная модель |
| Просрочка | Заказ не завершён, а первоначальный срок раньше учебной даты |
| Риск задержки | У активного заказа прогноз позже первоначального срока; может сочетаться с просрочкой |
| DEMO_DATE / учебная дата | Фиксированное 30.09.2026 для расчётов сроков; не текущее время событий |
| Следующее действие / следующая задача | Текст очередного шага заказа и его срок. Не обязательно отдельная задача Telegram |
| Задание исполнителя | Запись tasks для замера/монтажа с назначением, сроком и статусом |
| Проблема | Подтверждённое описание затруднения, тип и требуемая помощь; текущая проблема заказа одна |
| Координатор | Сотрудник, который разбирает проблемы и стоимость переделки; Telegram-адресат задан общей настройкой |
| Замерщик | Исполнитель замера; сдача его задания переводит заказ в проектирование |
| Монтажник | Исполнитель монтажа; сдача его задания переводит заказ в приёмку |
| Приёмка | Стадия после монтажа, где нужно согласовать акт; заказ ещё активен |
| Выручка | Сумма по заказу с учётом скидок, в рублях без НДС в учебной модели |
| Переменные затраты | Материалы, изготовление, доставка, монтаж, комиссия и переделки |
| Переделка | Статья расходов на переделки/рекламации; admin меняет её общую фактическую сумму |
| Маржинальный доход | Выручка минус перечисленные переменные затраты; не чистая прибыль |
| Маржинальность | Доля маржинального дохода в выручке, в процентах; при нулевой выручке не рассчитывается |
| Низкая маржинальность | Процент строго меньше 15%; отдельный признак отрицательного дохода также попадает в общий KPI |
| Неполные данные / NULL | Известны не все нужные фактические суммы; это не подтверждённый нулевой расход |
| План / факт | Независимые ожидаемые и фактически введённые суммы; одно не подставляется за другое |
| Dashboard / сводка | Верхняя часть главной: KPI, графики, экономика и краткий список внимания |
| KPI | Числовой индикатор, например число просроченных; здесь по нему можно фильтровать доску |
| Checklist | Список проверок перед сдачей работы; подтверждается одной общей кнопкой |
| История | Последовательность событий заказа с источником, временем и пояснением |
| API | HTTP-адреса, через которые браузер получает данные и сохраняет переделку |
| Webhook | Адрес backend, куда Telegram сам присылает сообщения и нажатия кнопок |
| Backend | Python-приложение, которое проверяет действия, работает с БД и рассчитывает показатели |
| Frontend | HTML/CSS/JavaScript, который пользователь видит и использует в браузере |
| SQLite | Файловая база проекта; хранит заказы, задачи, историю и Telegram-состояния |
| Seed | Команда заполнения учебного набора; обычный запуск не очищает существующие заказы |
| Имитация / simulation | Отдельный локальный пример интерфейса без записи в рабочую БД и без отправки Telegram |
| Outbox | Сохранённая очередь исходящих сообщений, которую обрабатывает backend |
| update_id | Идентификатор входящего Telegram update; одинаковый номер повторно не применяется |
| Nonce | Случайная метка текущего диалога, по которой бот отличает новую кнопку от устаревшей |
| Идемпотентность update | Повтор того же update_id не повторяет бизнес-изменение и постановку сообщений |
| Stale data | Последний успешно загруженный снимок, оставшийся после ошибки обновления; может быть устаревшим |
| Basic Auth | Запрос браузером логина/пароля для admin; не общая регистрация пользователей |
| Reverse proxy / Caddy | Сервер перед backend, который принимает HTTPS и передаёт запросы приложению |
| systemd | Менеджер Linux, запускающий и перезапускающий сервис kitchen-control |
| WAL | Дополнительный журнал SQLite; при backup/restore нельзя забывать его связь с файлом базы |
