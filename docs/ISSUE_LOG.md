## Проверенные риски без наблюдённого сбоя

- HTTPS: валидный сертификат с правильным SAN проверен снаружи, browser не игнорирует TLS errors.
- Webhook secret: запросы без секрета и с неправильным секретом реально вернули 403 на публичном сайте.
- Admin: запрос без credentials вернул 401; валидация, HTTPS-only и защита от cross-origin мутаций покрыты тестами.
- SQLite permissions: непривилегированный процесс работает; через admin выполнена и прочитана запись в production SQLite.
- Duplicate updates: тест проверяет одно бизнес-событие и одно уведомление; отдельный конкурентный тест — четыре одинаковых update одновременно.
- Database locks: транзакции короткие, сетевой Telegram вызов не держит SQLite write lock; конкурентный duplicate test проходит.
- NULL и ноль: разные значения в базе, расчётах, API и интерфейсе; неполные расходы не подменяются планом.
- Сроки: исходный срок не меняется при запросе переноса, завершённые заказы не считаются активной просрочкой.
- Stale data: браузером искусственно прерван API-запрос, timestamp остался прежним, предупреждение показано.
- Cache: динамический API отдаёт `Cache-Control: no-store`, fetch использует `cache: no-store`.
- Restart: start/stop/restart нового сервиса выполнены, бизнес-данные сохранились.
- Backup: SQLite backup API, `integrity_check=ok`, 24 заказа в резервной копии.
- Доступность соседних сайтов после Caddy reload: проверены HTTP 200.

## Диагностические замечания

Установленная версия Starlette выводит предупреждение об устаревании httpx transport в TestClient. Тесты проходят; runtime приложения использует httpx для Telegram независимо от TestClient. Зафиксированные версии сохранены в requirements-lock.txt.

Caddy сообщает о форматировании ранее существующей конфигурации. `caddy validate` проходит; весь чужой Caddyfile не переформатировался ради этого предупреждения.

Отдельная отметка: неизвестный Telegram ID, отсутствие coordinator allowlist или недоставка сообщения должны отражаться явно, а не считаться успешным end-to-end. Итог живой проверки указан в TEST_RESULTS.md.
