## Что нужно для окончательной приёмки

Открыть бота с тестовых аккаунтов, добавить Telegram ID в allowlist, назначить координатора и выполнить сценарий из DEMO.md. После этого дополнить таблицу фактическими update_id/временем, проверить SQLite, историю и публичный сайт, сохранить реальные Telegram-скриншоты. До этого весь проект не объявляется полностью проверенным end-to-end.
