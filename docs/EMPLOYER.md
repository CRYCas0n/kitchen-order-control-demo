# Два абзаца для работодателя

Собрал и развернул небольшой инструмент контроля заказов кухонной фабрики: на одной странице видны сроки, проблемы, следующие действия и экономика 24 учебных заказов. Сообщение монтажника из Telegram сохраняется в базе, появляется на публичном сайте и автоматически отправляется координатору. В защищённом интерфейсе координатор меняет стоимость переделки и сразу видит влияние на маржинальный доход. Использованы Python/FastAPI, SQLite и обычный JavaScript; сайт работает по HTTPS. Оба потока проверены, в том числе с двумя настоящими Telegram-аккаунтами; завершение монтажа переводит заказ в приёмку, не закрывая его автоматически.

После финального ревью проходят 39 автоматических тестов; отдельно выполнены проверки настоящим браузером. Проверены расчёты, сроки, различие NULL и нуля, повторные updates, доступ к чужим заданиям, ошибки связи и сохранность данных после restart. В предыдущем живом Telegram-сценарии монтажник сначала отправил проблему до подключения координатора, поэтому уведомление не ушло; причина записана в истории. После подключения второго аккаунта доставил сохранённую проблему, затем отдельно проверил новую: уведомление ушло автоматически, владелец подтвердил получение координатором. Базу, историю и публичную карточку сверил с настоящими сообщениями; подтверждён переход монтажа в «Приёмку». Новый прогон в Telegram после финальных исправлений не выполнялся по выбору владельца; прежние подтверждения сохранены в [TEST_RESULTS.md](TEST_RESULTS.md).
